1. ข้อมูลธุรกิจและปัญหาที่ต้องการแก้ไข

ธุรกิจ: DPS (Distance Per Stroke) เป็นเอเจนซี่และแพลตฟอร์มกีฬาว่ายน้ำครบวงจรในประเทศไทย ให้บริการจัดการแข่งขัน รายงานผลการแข่งขัน วิเคราะห์ข้อมูลประสิทธิภาพ (pacing / split / Distance Per Stroke) เอเจนซี่นักกีฬา ทุนการศึกษา สื่อ/พอร์ตโฟลิโอ และร้านค้าสปอร์ตแฟชั่น

กลุ่มผู้ใช้: โค้ช, สโมสร, นักกีฬา, ผู้จัดแข่งขัน, ผู้ปกครอง, ผู้ดูแลระบบ (Admin)

ปัญหาที่พบ

  • ข้อมูลผลการแข่งและ split กระจายใน Excel/CSV ไม่รวมศูนย์
  • การวิเคราะห์ pacing จากวิดีโอยังทำด้วยมือช้า เทียบกับเครื่องมืออย่าง Mako Vision
  • ไม่มีระบบเดียวที่เชื่อมปฏิทินแข่ง → รายงานผล → analytics → วิดีโอ
  • ยากต่อการเปรียบเทียบนักกีฬาข้ามสโมสรหรือข้ามรายการแข่งขัน
เป้าหมายระบบ BlueHub: เป็น Digital Hub ว่ายน้ำที่เปลี่ยนสถิติและคลิปแข่งให้เป็นข้อมูลตัดสินใจของโค้ชได้อย่างรวดเร็ว

3. Structured Requirements

Functional Requirements

  • FR-01 อัปโหลด/นำเข้าข้อมูลผลการว่ายน้ำ
  • FR-02 กรองตามเพศ, รุ่นอายุ, สโมสร, นักกีฬา
  • FR-03 แสดงกราฟ Pacing / Cumulative (Recharts)
  • FR-04 สร้าง Video Session + แท็กระยะด้วยมือ (ปุ่ม Q) และ AI
  • FR-05 คำนวณ split และ cumulative จากจุด Start ของการแข่ง
  • FR-06 Login Admin + CRUD ข้อมูลหลัก

Non-Functional Requirements

  • NFR-01 ใช้งานบนเว็บผ่านเบราว์เซอร์ (Responsive)
  • NFR-02 รองรับวิดีโออัปโหลดสูงสุดประมาณ 200MB (MVP)
  • NFR-03 แยก AI worker (Python) ออกจากเว็บ เพื่อไม่บล็อก UI
  • NFR-04 เก็บรหัสผ่าน Admin ผ่าน environment variables / cookie session
  • NFR-05 UI ใช้ธีมแบรนด์ DPS (น้ำเงิน–ฟ้า)

Actors: Coach, Athlete (ดูผล), Admin, System (AI Worker)

10. Data Privacy & Governance Plan

ประเด็นแนวทาง
ข้อมูลส่วนบุคคลชื่อนักกีฬา สโมสร คลิปแข่ง — เก็บเท่าที่จำเป็นต่อเซสชันวิเคราะห์
การยินยอมโค้ช/สโมสรรับผิดชอบสิทธิ์คลิปก่อนอัปโหลด
การเข้าถึงแยก Admin จากผู้ใช้ทั่วไป รหัสผ่านผ่าน env
การเก็บวิดีโอเก็บในเซิร์ฟเวอร์โปรเจกต์ ไม่ส่งออกนอก worker โดยไม่จำเป็น
Retentionลบเซสชัน/ไฟล์เมื่อเสร็จงาน หรือครบกำหนด (เช่น 90 วัน)
Prompt / AIไม่ใส่ข้อมูลอ่อนไหวเกินจำเป็นใน log ของ job
Complianceแนวทาง พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA)

12. สรุปแนวทางการพัฒนาระบบ

แนวทาง: พัฒนาแบบ Incremental / Phased

  1. Phase 1 — Core platform: ปฏิทิน, ผลแข่ง, Analytics CSV, Shop, About
  2. Phase 1.5 — Admin + ฐานข้อมูลจริง + Payment
  3. Phase 2 — Video Analysis (แท็กมือ + AI Suggest) มีหน้าใช้งานแล้วที่ /analytics/video
